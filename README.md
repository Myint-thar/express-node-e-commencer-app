# E-commerce Project (Node.js, Express, MySQL, EJS)

ဤပရောဂျက်သည် Node.js နှင့် Express.js တို့ကို အသုံးပြု၍ ရေးသားထားသော ရိုးရှင်းသည့် အွန်လိုင်းဈေးဝယ်စနစ် (E-commerce) ဖြစ်ပါသည်။ အချက်အလက်သိမ်းဆည်းရန်အတွက် MySQL ကို အသုံးပြုထားပြီး၊ Frontend UI အတွက် EJS template engine ကို အသုံးပြုထားပါသည်။

## အသုံးပြုထားသော နည်းပညာများ (Tech Stack)
* **Backend:** Node.js, Express.js
* **Database:** MySQL
* **Template Engine:** EJS

## အဓိကလုပ်ဆောင်ချက်များ (Key Features)
* ကုန်ပစ္စည်းများကို အမျိုးအစားအလိုက် ကြည့်ရှုနိုင်ခြင်း။
* မိမိဝယ်ယူလိုသော ပစ္စည်းများကို Cart (ဈေးဝယ်ခြင်းတောင်း) ထဲသို့ ထည့်သွင်းနိုင်ခြင်း။
* အသုံးပြုသူများ အကောင့်ဖွင့်ခြင်း နှင့် လော့ဂ်အင်ဝင်ခြင်း။
* အော်ဒါတင်ခြင်း (Checkout) နှင့် မှတ်တမ်းများ ပြန်လည်ကြည့်ရှုနိုင်ခြင်း။
